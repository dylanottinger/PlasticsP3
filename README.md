# P3 — Plastics Manufacturing Website

Static site (plain HTML/CSS/JS, no build step). Hosted on Cloudflare Pages.

- Pages: `index.html`, `services.html`, `industries.html`, `about.html`, `contact.html`, `404.html`
- Styles: `css/styles.css` · Script: `js/main.js`
- Preview locally: `python3 -m http.server 8000` → http://localhost:8000
- Yellow **TBD** / **Client to supply** tags mark placeholder content.
- Header/footer are duplicated in each page; update all of them when changing nav.
